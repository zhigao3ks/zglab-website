## 项目背景

通用简历难以充分体现不同岗位关注的能力。本项目探索如何利用 Agent 和个人知识库，实现面向具体岗位的简历工程化生成。

## MCP 架构

系统通过 MCP 将个人资料、项目经验和分析能力组织为可调用资源与工具，使 Agent 能够基于真实经历完成检索、分析和生成。

## 应用流程

覆盖岗位 JD 解析、经历匹配、内容重写和结果检查，形成从岗位理解到简历输出的完整工作流。
